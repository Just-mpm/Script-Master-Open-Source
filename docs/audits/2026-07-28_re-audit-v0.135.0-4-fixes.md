## Verificação Detalhada das 4 Correções

### Item 1 ✅ — JSDoc do `appDrawerBackdropSx` corrigido

**Arquivo:** `src/theme/surfaces.ts:70-77`

**Problema original (v0.134.0):** O JSDoc do `appDrawerBackdropSx` tinha dois objetos `slotProps` separados — o segundo sobrescrevia o primeiro, resultando em código JSX inválido:
```tsx
// ❌ Antes:
<Drawer
  slotProps={{ backdrop: { sx: appDrawerBackdropSx } }}
  slotProps={{ paper: { sx: appDrawerPaperSx } }}
>
```

**Estado atual — corrigido:**
```tsx
// ✅ Agora:
<Drawer
  slotProps={{
    backdrop: { sx: appDrawerBackdropSx },
    paper: { sx: appDrawerPaperSx },
  }}
>
```

**Confidence:** 100/100

### Item 2 ✅ — Sidebar.tsx migrada para spread + imports limpos

**Arquivo:** `src/components/app/Sidebar.tsx`

**Problema original:** A Sidebar duplicava inline `backgroundColor`, `backgroundImage` e `borderRight` em vez de usar o helper compartilhado. Também importava `APP_SURFACE`, `WHITE_05`, `WHITE_015` sem usá-los.

**Estado atual:**

```tsx
// Linha 36 — import correto:
import { appDrawerPaperSx } from '../../theme/surfaces';

// Linhas 134-148 — uso com spread:
slotProps={{
  paper: {
    sx: {
      ...appDrawerPaperSx,   // ✅ backgroundColor, backgroundImage, borderRight
      width,                  // ✅ sobrescreve largura dinâmica
      boxSizing: 'border-box',
      transition: widthTransition,
      overflowX: 'hidden',
      backdropFilter: 'blur(22px)',
      WebkitBackdropFilter: 'blur(22px)',  // ✅ novo (Safari)
      height: '100dvh',
      zIndex: 1200,
    },
  },
}}
```

**Imports removidos:** `APP_SURFACE`, `WHITE_05`, `WHITE_015` — não usados. `APP_BORDER` mantido (usado no `Divider` linha 159). ✅

**Novo na Sidebar:** `WebkitBackdropFilter: 'blur(22px)'` foi adicionado junto com a migração — correção de compatibilidade Safari que antes não existia neste componente. Melhoria, não regressão.

**Confidence:** 100/100
